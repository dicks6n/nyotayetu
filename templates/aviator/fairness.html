Provably Fair

Every crash point is sealed before the round starts — and you can verify it.

How it works
  1. Before betting opens, the server picks a random server seed and shows you sha256(seed).
  2. The crash point is computed from HMAC_SHA256(seed, "{{ hmac_key }}").
  3. With r = first 13 hex digits ÷ 252: crash = (1 − {{ house_edge }}%) ÷ (1 − r). Return to player is {{ rtp }}% for every strategy.
  4. After the plane flies away, the seed is revealed. Hash it — it must match the hash you saw.
